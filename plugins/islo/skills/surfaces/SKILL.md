# Run surfaces

Read [Surface usage](references/usage.md) before publishing a live interface from a line-run stage sandbox.

Only a stage agent with the line-run Surface environment invokes `islo surface`. A Line Manager can use this guidance to route a Surface request to the stage agent that owns the sandbox.
