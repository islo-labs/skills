# Factory Machines

Use this skill when working inside a Factory Machine build or a stage backed by a Machine snapshot. The Machine CLI and discovered stack determine what can run. Read [Machine lifecycle](references/lifecycle.md) for build, inspection, verification, and snapshot preparation. Read [Live run surfaces](references/surfaces.md) when a line run should show useful interfaces.

For creating or operating a Machine resource from outside its stage sandbox, use the `factory-lines` skill's Machine commands.
